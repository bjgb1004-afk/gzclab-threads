# 복권명당 기능 정리 (2026-11-14, 앱 코드 ruflo-starter 기준)

공개 기능만 적었다. 관리자 전용 '번호 분석실'은 제외. 홍보 글은 이 문서의 사실만 쓴다.

## 탭
| 기능 | 위치 | 하는 일 | 근거·숫자 |
|---|---|---|---|
| 명당 지도 | 지도 탭(첫 화면) | 내 위치 주변 1등 배출 판매점을 마커로. 지도 이동하면 그 지역 기준으로 재조회 | 위치 거부 시 서울시청 기준으로 표시 |
| 명당 랭킹 | 랭킹 탭 | 17개 시·도 선택 → 시도 전체 순위, 시·군·구 선택 → 그 구 안에서 상위 100곳 | 구 순위는 서버에서 구 기준으로 다시 조회 |
| 당첨확인(QR) | 당첨확인 탭 | 용지 QR 스캔, 보관함 자동 저장, 추첨 후 맞은 번호만 색칠, 동행복권 원본 확인 | 자동촬영(연속촬영) 모드: 창 없이 바로 저장 |

## 판매점 상세
| 기능 | 하는 일 | 근거·숫자 |
|---|---|---|
| 명당지수 | 0~100점 | 최근 1년 1등×50 + 최근 1년 2등×10 + 누적 1등×5 를 환산 |
| 당첨 이력·영업시간 | 1등 회차별 자동/수동/반자동 표시, 영업시간 요일 묶음 표시 | |
| 명당알림 | 고른 판매점 근처 도착 시 알림(앱 꺼져 있어도) | 무료 2곳까지, 고른 판매점 위치만 사용 |
| 즐겨찾기 | 별 누르면 저장 | 로그인 시 클라우드(기기 간 동기화), 아니면 기기 저장 |

## 더보기
| 기능 | 하는 일 | 근거·숫자 |
|---|---|---|
| 천재들의 한수 | 아르키메데스·피보나치·파스칼·오일러·가우스 방식 분석 번호 | 스레드 아침 번호 글과 같은 번호. "통계 참고용, 확률 안 높여줌" 고지 |
| 현재까지 나간 번호 | 이번 회차 추첨 전 코너별로 나간 게임 수 | 순위 아님(게임 수 순 정렬) |
| 번호대 분석 | 다섯 구간 중 하나 비우고, 한 구간 최대 3개, 저고 2:4·3:3·4:2 | 첫 화면 '오늘의 추천'(날짜 시드, 스레드 토요일 번호와 같음), 다시 뽑기는 완전 무작위 |
| 놓친 당첨금 | 번호 6개로 지난 회차 전부 샀다고 치고 계산 | 전체 회차 기준 평균 23번 당첨(최소 12번). "번호가 아니라 회차 수" 고지 |
| 스피또 현황 | 판매 중 회차를 1등 잔여 많은 순으로, 판매 끝난 회차는 지급 마감 경고 | 입고율·잔여 금요일 기준 주 1회 갱신 |
| 회차별 당첨현황 | 1회~최신 회차 1·2등 배출점, 구매 방식 | 지역별 명당 밀도(행운 지수) 포함 |

## 내 복권(보관함)
| 기능 | 하는 일 |
|---|---|
| 수익률 | 구매액 vs 당첨금 막대 비교. 산 복권과 번호만 저장한 것은 따로 계산 |
| 자주 뽑은 번호 | 내가 자주 고른 번호 모아보기 |
| 이미지 공유 | 화면을 이미지로 공유 |
| 번호 직접 입력 | 6개 입력(일부만 고르고 나머지 자동 가능) → 추첨 후 자동 확인 알림 |
